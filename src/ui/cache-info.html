Using this binary cache

flakemill serves its own Nix store as a signed binary cache, so hosts can download build results straight from the mill instead of waiting for them to reach Cachix.

1. Get the two values

The substituter URL is simply this instance's address with /cache appended; the key is published next to it: 

curl -fsS https://<mill-url>/cache.pub   # signing key to trust

The dashboard's "cache" rows copy both, and the "nix.conf" button copies the whole block below in one go.

2. Configure each host

Drop-in for /etc/nix/nix.conf:

extra-substituters = https://<mill-url>/cache?priority=10
extra-trusted-public-keys = <contents of /cache.pub>

Or in NixOS configuration:

nix.settings.extra-substituters = [ "https://<mill-url>/cache?priority=10" ];
nix.settings.extra-trusted-public-keys = [ "flakemill-cache:…" ];

On NixOS the user must be in nix.settings.trusted-users (or nixUsers) for extra substituters to apply.

3. Why the priority

Nix consults substituters in ascending order of the priority each cache advertises: cache.nixos.org publishes 40 and Cachix 41, and this cache advertises 30. Writing ?priority=10 in the URL pins the mill in front of both, which is what you want for freshly published systems; drop it if you would rather the public caches answer first.

Priority only says where to look first. Paths are still signature-checked, so a host that does not trust the key above will refuse everything the mill offers, and a host that does will never accept a path signed by someone else.

Notes

  • The cache answers for paths already in the mill's store. It does not forward requests to Cachix or cache.nixos.org; hosts keep those as upstreams.
  • It is a plain HTTP endpoint with no authentication: anyone who can reach it can download anything in the store. Terminate TLS in front of flakemill (or restrict the network) and set PUBLIC_URL so the advertised URL matches what hosts actually use.
  • Garbage collection still removes unpublished paths, so the cache is a convenience, not an archive. Cachix remains the durable push target.
